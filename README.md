# NEXUS

Asistente personal de inteligencia artificial para Windows.

## Objetivo
Construir un asistente capaz de conversar por voz en español,
mantener memoria y ejecutar tareas autorizadas en el equipo.

## Tecnologías principales
- Python
- FastAPI
- OpenAI API / Realtime API
- Porcupine para detección local de palabra de activación
- PostgreSQL
- Qdrant
- n8n
- Playwright
- PowerShell
- HTML, CSS y JavaScript
- Git y Docker

## Estado
